# Aion — резервные копии как в Time Machine

Aion хранит историю домашней папки: каждый снимок — дерево жёстких ссылок
`rsync`, поэтому новая копия занимает только изменившиеся байты. В окне виден
таймлайн снимков, любой из них можно просмотреть как в файловом менеджере и
восстановить отдельный файл, папку или целое дерево.

## Установка

```bash
sudo pacman -S qt6-base qt6-declarative kirigami qqc2-desktop-style rsync
cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
cmake --install build --prefix "$HOME/.local"
```

После установки приложение запускается командой `aion` и появляется в меню
«Система».

## Первый запуск

Настройки по умолчанию:

- папка копий — `/data/Backup` (если `/data` доступна на запись);
- источники — `~/.config`, `~/.local`, `~/Music`, `~/Pictures`, `~/Videos`,
  `~/.bashrc`, `~/.bash_profile`;
- исключения — `~/.local/share/Steam`, `~/.local/share/twintaillauncher`,
  `~/.local/share/Trash`;
- хранение — почасовые за последние сутки, ежедневные за 30 дней,
  еженедельные за 12 недель;
- язык — системный, иначе английский.

Нажмите **«Создать резервную копию»**. Первый снимок — полная копия, все
следующие — инкрементальные.

## Окно

- Слева — таймлайн: снимки сгруппированы по дням, последний помечен
  «Последняя».
- Справа — содержимое выбранного снимка: навигация по папкам, выбор элементов
  галочкой, кнопка «Восстановить».
- Внизу — состояние: скорость, оставшееся время, объём и свободное место.
- Меню (кнопка в заголовке) — создать копию, восстановить, настройки, «О
  программе».

## Настройки

- **Общие** — папка копий, язык (переключается сразу), уведомления, одно окно,
  сохранение ACL и расширенных атрибутов.
- **Источники** — что копировать и что исключать. Отсутствующие источники
  пропускаются с предупреждением.
- **Расписание** — автоматические копии через systemd-таймер пользователя;
  работает и при закрытом окне.
- **Хранение** — окна прореживания и кнопка «Проредить сейчас».

## Восстановление

Выберите элементы в снимке и нажмите «Восстановить…». Можно вернуть их на
исходное место (по умолчанию) или в выбранную папку — тогда сохраняется вся
структура пути. Если файл уже существует, выберите «Заменить», «Оставить
существующий» или «Сохранить оба» (восстановленная копия получит имя
`имя (восстановлено <дата>)`).

Восстановление в исходное место перезаписывает файлы — это ожидаемое
поведение, но на всякий случай сначала можно восстановить в отдельную папку и
сравнить.

## Командная строка

```bash
aion --backup                 # создать снимок
aion --list                   # список снимков
aion --prune                  # применить политику хранения
aion --restore <id> <путь>... [--to ПАПКА] [--policy overwrite|skip|keep_both]
aion --print-config           # показать действующие настройки
```

Пути в `--restore` задаются относительно корня снимка, например
`home/soneriald/.config/kdeglobals`.

## Где что лежит

| Путь | Содержимое |
|---|---|
| `~/.config/aion/aion.conf` | настройки |
| `~/.cache/aion/aion.log` | журнал приложения |
| `~/.cache/aion/logs/backup-<id>.log` | полный вывод rsync одного запуска |
| `~/.config/systemd/user/aion-backup.*` | юниты автоматических копий |

Подробно про формат снимков — в
[`docs/BACKUP-FORMAT.md`](../BACKUP-FORMAT.md).
