# Kustos — резервные копии как в Time Machine

Kustos хранит историю домашней папки в зашифрованном, сжатом и
дедуплицированном репозитории формата restic. В окне виден таймлайн снимков,
любой из них можно просмотреть как в файловом менеджере и восстановить
отдельный файл, папку или целое дерево.

Движок — `rustic` (Rust, формат restic): шифрование AES-256, сжатие zstd,
дедупликация по содержимому. Приложение написано на Rust, интерфейс —
QML/Kirigami.

## Установка

```bash
sudo pacman -S qt6-base qt6-declarative kirigami qqc2-desktop-style rustic
cd ~/Projects/kustos
makepkg -si          # собирает из рабочего дерева и ставит пакет
```

После установки один раз откройте **«Настройки → Расписание»**: юнит
systemd перезапишется с `ExecStart=/usr/bin/kustos`.

## Первый запуск

- Репозиторий: `/data/Backup/kustos` (если `/data` доступна на запись).
- Копируются: `~/.config`, `~/.local`, `~/Music`, `~/Pictures`, `~/Videos`,
  `~/.bashrc`, `~/.bash_profile`.
- Исключены: `~/.local/share/Steam`, `~/.local/share/twintaillauncher`,
  `~/.local/share/Trash`.
- Хранение: почасовые за сутки, ежедневные за 30 дней, еженедельные за 12
  недель.

Кнопка **«Создать резервную копию»** открывает окно **«Что копировать»**: там
редактируются списки копируемых папок/файлов и исключений. Исключения могут
находиться внутри копируемых папок. Тот же список доступен из
**Настройки → Что копировать…**.

## Ключ репозитория

Ключ создаётся при первом запуске и лежит в `~/.config/kustos/repo.password`
(права 0600). Это единственный способ прочитать копии: покажите его в
**«О программе»** и сохраните отдельно — в менеджере паролей или на бумаге.
Если ключ потерян, данные не восстановить.

## Восстановление

Выберите элементы в снимке и нажмите «Восстановить…». По умолчанию файлы
возвращаются на исходное место; можно выбрать папку — тогда сохраняется вся
структура пути. Если файл уже существует: «Заменить», «Оставить существующий»
или «Сохранить оба» (копия получит имя `имя (restored <дата>)`).

## Командная строка

```bash
kustos --backup                 # создать снимок
kustos --list                   # список снимков
kustos --prune                  # применить политику хранения
kustos --restore <id> <путь>... [--to ПАПКА] [--policy overwrite|skip|keep_both]
kustos --print-config           # действующие настройки
```

Пути в `--restore` задаются относительно корня снимка, например
`home/soneriald/.config/kdeglobals`.

## Автоматические копии

**Настройки → Расписание** включает systemd-таймер пользователя
(`~/.config/systemd/user/kustos-backup.{service,timer}`), который запускает
`kustos --backup --quiet` каждые N минут, первый раз через 5 минут после
включения. Таймер работает и при закрытом окне.

## Где что лежит

| Путь | Содержимое |
|---|---|
| `~/.config/kustos/kustos.json` | настройки |
| `~/.config/kustos/repo.password` | ключ репозитория (0600) |
| `~/.cache/kustos/kustos.log` | журнал приложения |
| `~/.config/systemd/user/kustos-backup.*` | юниты таймера |

Подробнее про формат — в [`docs/BACKUP-FORMAT.md`](../BACKUP-FORMAT.md).
