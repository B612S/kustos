# Kustos icon concepts

Five Papirus-style proposals. Variant 2 (*Snapshot Stack*) was chosen and is
now installed as `assets/kustos.svg` and `assets/kustos.png`; the other four
remain here as alternatives.

Every file uses a 64×64 viewBox and is exported to
`png/{32,48,64,128,256}/`. The visible tile is 28×28 px at the 32 px menu size,
matching the Discord/KeePassXC icons in the reference launcher.

| # | File | Idea | Colour |
|---|---|---|---|
| 1 | `kustos-rewind-blue.svg` | clock inside a rewind ring — the closest to the current icon | Papirus blue |
| 2 | `kustos-snapshot-stack.svg` | three stacked snapshot layers — **installed** | teal |
| 3 | `kustos-hourglass-amber.svg` | hourglass for time passing | amber |
| 4 | `kustos-shield-green.svg` | shield with a clock face — encrypted and time-aware | green |
| 5 | `kustos-folder-violet.svg` | folder with a rewind ring, Papirus folder-style | violet |

## Installed

Variant 2 was installed on request: its SVG is the application icon and its
256 px PNG is embedded in the window and About dialog. The 32/48/64/128 px
exports in `png/` can be used for a Papirus theme or a launcher entry.
